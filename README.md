# Loan Approval Prediction Using Machine Learning

## Project Overview
This project focuses on predicting loan approval outcomes using supervised machine learning algorithms.

The objective is to apply machine learning techniques to a real-world dataset and compare the performance of different classification algorithms.

## Algorithms Implemented
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Naive Bayes

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib / Seaborn
- Scikit-learn

## Workflow
1. Data loading and exploration
2. Data preprocessing
3. Exploratory Data Analysis
4. Model implementation and training
5. Model evaluation
6. Performance comparison

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Key Learning Outcomes
- Understanding supervised machine learning algorithms.
- Applying data preprocessing techniques.
- Implementing classification models.
- Evaluating and comparing model performance.
